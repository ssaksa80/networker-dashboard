    What every option includes

    No CDN, no new libraryAll motion is plain CSS and a few lines of JavaScript, so it works on the air-gapped hosts and under the current Content-Security-Policy.
    All 15 themes keep workingThe glow is coloured from each theme's --glow, so a theme change recolours it.
    Reduced motion respectedMotion has Full, Subtle and Off. A system "reduce motion" setting forces Off, which shows the final state at once.
    Sidebar that docks or floatsDocked, collapsed to icons, or floating: drag it anywhere, double-click its header to park it, minimise it to a glowing button.
    Admin console as its own page/admin, with the 12 sections shown here, its own sign-in, and an audit log of every change.
    Same security rulesJSON-only POSTs, same-origin check, CSRF token, secrets never sent back to the browser.

    How the admin console maps to DEDB's

    DEDB's console gates on a signed-in admin role. NetWorker Dashboard has one gateway password and no user accounts, so the gate becomes: signed in, and (optionally) the password typed again before admin changes. With no password set, /admin opens only on the server itself, and offers to set one first, like DEDB's setup wizard.

    What I need from you

    1. Pick an option (A, B, C or D). Mixing is fine, for example "B for the dashboard, D for the admin console".
    2. Admin navigation: DEDB's tab strip, or the grouped list on the left.
    3. Password again before admin changes: yes or no. It is the nearest match to DEDB's admin role.
    4. First release: all 12 sections, or start with the ones that already have server routes and add Sessions, Audit, Logs and TLS next.
